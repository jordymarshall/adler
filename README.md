# adler
Personal goal coach, trained on psychology and behavioral science methodologies to help you achieve goals.

## Where things are

- `docs/method/adler-method.md` — the Adler Method, the source of truth for what the app does. Versions in `docs/method/versions/`; panel findings in `docs/method/panel-round-*.md`.
- `docs/decisions.md` — product decisions D1–D19.
- `docs/research/` — evidence base: `behavioural-science-synthesis.md` (start here), `deep/README.md` (index of 23 deep dives), plus coaching, goal-discovery, training-science, accreditation, agent-engineering, voice and landing research.
- `landing/` — Astro landing site. `cd landing && npm install && npm run dev`.
