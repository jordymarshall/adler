# One coaching system behind every interface

Adler's product is the shared coaching system, including methodology, model policy, tools, context and learning memory. Web, messaging, MCP and intelligent app controls are adapters into that system, because separate reasoning or learning paths would make the product behave differently depending on where the person uses it. Deterministic commands remain proportionate and use the same validation and state; this choice does not require a language-model call for every click.

The existing shared runtime is the implementation starting point. Closing its divergent paths and adding live hypothesis/test records follows the [engineering design](../method/coaching-engineering.md); recording this decision does not assert that migration is complete.
