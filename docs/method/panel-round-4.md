1. **§5.4, Coach replies by barrier, opening rule**
   - Current: One reflection line plus one optional question the user can ignore; the user's answer gets one reflection and the exchange ends there, with no further question.
   - Proposed: One reflection line plus one optional question the user can ignore, and one reflection on the answer. Two barriers carry a scripted offer after that reflection and nothing else does: Too hard always, and Didn't feel like it only after two setup changes have been tried. 2. **§4, Counting rule, the rotation sentence**
   - Current: The review card asks automaticity and confidence for one build action per week on rotation, so every build action is read at least once a fortnight and a gate needing two consecutive readings uses the two most recent readings for that action; every other action contributes to counts only.
   - Proposed: The review card asks automaticity and confidence for one build action per week on rotation, so at two build actions each is read every second week and at three every third.    - Why: 'At least once a fortnight' is arithmetically false at three build actions, which §3 and §5.7 both permit, and the error is not cosmetic: §5.7's hold gate wants two consecutive readings inside fourteen days and §7.10 wants eight readings inside a trailing eight weeks, neither of which a three-week rotation can supply.
