# Deep research index

One line per file: the single most decision-relevant finding. Full effect sizes, conflicts and product rules are inside each file. The consolidated view is `../behavioural-science-synthesis.md`.

## Deep dives (`docs/research/deep/`)

| File | The one finding that matters most |
|---|---|
| `bct-effectiveness.md` | The variable is **monitoring performed, not monitoring offered**: Harkin's experimental d = 0.40 holds where monitoring is objective and actually done, and goes null or negative (Carraça β = −1.04) where an app merely offers a log; no BCT count effect survives once human contact is controlled. |
| `adaptive-interventions.md` | JITAIs are worth **g = 0.15** (von Lützow 2025), not 1.65; notifications buy the next hour (OR 3.5) and change retention not at all (Drink Less MRT); message effects habituate to zero by ~day 28 (HeartSteps). |
| `self-regulation-theory.md` | Affect tracks the **rate** of progress against an expected rate, not the distance to the goal; and self-efficacy is mostly a readout of recent mastery (performance → efficacy β = .205 vs efficacy → performance .071, Talsma 2018). |
| `motivation-science.md` | **Immediate** rewards predict persistence, delayed ones predict only intentions (Woolley & Fishbach); people put off *effort*, not money (Augenblick β ≈ 0.88 vs 0.97); grit is conscientiousness relabelled (Credé ρ = .18, r with C = .84). |
| `habit-science-deep.md` | Automaticity lives in **instigation**, not execution, and time-to-habit is per behaviour: ~2 months for a simple daily act, **122–226 days** for gym attendance (Buyalskaya, 12M check-ins). Reminders build repetition but hinder automaticity. |
| `lapse-relapse-recovery.md` | The abstinence-violation effect does not survive EMA data; what predicts the slide is **post-lapse recovery self-efficacy** (Kirchner HR 1.09), while internal blame was protective. Rewarding the *return* was the best of 54 arms in Milkman's megastudy (+27%). |
| `feedback-and-progress.md` | Feedback **content** is the moderator: high-information (task + process + self-regulation) d = 0.99 vs reinforcement/punishment 0.24 (Wisniewski, 435 studies); and the structured after-action review is the largest effect in the corpus (d = 0.67–0.79). |
| `maintenance-long-term.md` | Maintenance is a **schedule** change, not a curriculum: Cochrane's 81-trial null on relapse-prevention content and NoHoW's null against a tracker-plus-weighing active control, against replicated effects for *continued contact* (Middleton g = 0.385). |
| `social-accountability.md` | Harkin's subgroup table: monitoring **privately reported to someone** d+ = 0.47 (k = 95) vs unreported 0.19 (k = 14); the *public* cell that habit apps imitate rests on k = 3 with a CI spanning zero. |
| `individual-differences.md` | Tailoring on traits buys r ≈ .07, labels are not homogeneous groups (Sonuga-Barke), and ADHD coaching in exactly Adler's population moved **self-report but not GPA or credits** (Eddy 2021) — so the primary metric must stay behavioural. |
| `emotion-wellbeing-foundations.md` | Affect felt **during** the act predicts future behaviour; post-act affect is null (Rhodes & Kates). Also: strategy-situation "fit" failed a preregistered replication (Willroth 2025), so do not build a regulation-fit score. |
| `wisdom-and-perspective.md` | Self-distancing is small and condition-dependent (**g = 0.19**, PI −0.42 to 0.80; Murdoch 2023), best when keyed to emotional meaning (0.44) — and 32% of people execute the prompt wrongly unless it is verified. |
| `conversational-agents-evidence.md` | In **non-clinical** samples the chatbot effect on mood is g ≈ 0.07 and null for wellbeing/stress; behaviour change is the supported claim (SMD 0.2–0.6), and the active ingredient is accountability plus structure, not conversation (Schimpf 2026). |
| `meaning-values-purpose.md` | Meaning is the default, not a scarcity: **91%** of people across 132 nations say life has purpose (Heintzelman & King), so a "find your purpose" module pushes users into the *search* subscale, the one linked to slightly worse wellbeing. |
| `physical-foundations.md` | Sleep **regularity** beats duration (20–48% lower mortality across quintiles, Windred 2024), people cannot self-report their own impairment (Van Dongen), and half the activity guideline already carries RR 0.82 for depression. |
| `safety-risk-detection.md` | Every risk classifier is mostly wrong (PPV 5.5–17%), and LLM detection **degrades with conversational depth** while clinicians stay flat (Kalinich 2026) — an architecture problem, fixed by a stateless detector plus instruction re-anchoring (+0.12 F1). |
| `idiographic-inference.md` | A 7-vs-7-day comparison has an SE of ~25–30 pp: the weekly n-of-1 can only detect effects ~3× larger than anything in the corpus. "Two consistent verdicts" manufactures ~3.9 false personal rules per user-year; the ≥3 rule gives ~1.0. |
| `non-health-goal-domains.md` | Health-derived rules do **not** export: money moves on one structural change plus a goal-*naming* monthly reminder (+16% vs 0% unnamed), learning moves on spacing (g = 0.74) which contradicts the four-days-a-week floor, and a rejection is not a lapse. |
| `structural-limits.md` | Digital physical-activity interventions produce SMD **0.34 in high-SES and 0.06 in low-SES** participants, and no BCT choice moderates it; the honest claims ceiling for this product class is d ≈ 0.1–0.2 while contact continues. |
| `sex-cycle-and-gendered-context.md` | Cycle phase → performance ES = −0.06 and → cognition null across 730 comparisons, so store **nothing physiological**; instead let the user name a recurring low window, and note that the corpus's real external-validity gap is age (means 46–62), not sex. |
| `cultural-generalisability.md` | 96% of the base literature is Western; the exposed rules are exactly the tone rules — failure *raises* persistence in Japanese samples (Heine 2001), and socially expected obligation carries equal satisfaction and perceived choice in India (Miller 2011). |
| `depth-psychology.md` | Borrow questions, never formulations: secondary gain ("if this goal quietly disappeared, what would get easier?"), the tyranny of the should, and the record-over-narrative rule (Mazar & Wood: people misattribute habits to mood and intention). |
| `humanistic-existential-common-factors.md` | Chase 2013 is the strongest single finding for a goal app — **goal setting alone did nothing; values plus goal setting moved GPA** — and task/goal alliance predicts coaching outcomes where bond does not (de Haan 2016; Terblanche 2024). |
