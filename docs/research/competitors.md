## Five most common failure modes (churn)

1. Overload at setup: 8–15 habits day one, fail daily, quit in 2–3 weeks. Caps exist for revenue, not for user.
2. Streak / all-or-nothing anxiety: one miss → zero → guilt. Finch's zero-consequence answer reads as childish.
3. Passive tools never notice you left. "I used ChatGPT as accountability partner two weeks. Then I stopped opening it. It never noticed." Self-report bots congratulate lies.
4. Paywall/billing betrayal: trial auto-convert, platform price gaps (Finch 4x), surprise hikes.
5. Novelty decay + maintenance burden. AI variants add: forgets context, generic replies, canned options.

## What none do well (the opening)

- Diagnose the barrier, not just log the miss (COM-B / implementation-intention loop: capability, opportunity, motivation → shrink, re-cue, reschedule).
- Graceful failure by design: coached "never miss twice" recovery.
- Proactive, memory-backed outreach that is honest. Memory bar is high (Ash).
- Progressive loading: add habit #2 only when #1 is automatic. Fabulous is right in spirit, canned in execution.
- Verification used for coaching, not charging.

## How each handles multiple goals

Hard caps: Streaks 24, HabitKit 4 free, Habitify 3 free, Beeminder 3 free, Maxi 3 goals/5 habits, FineStreak 2–6. Unlimited: Coach.me, Finch, Oath. Forced focus: Fabulous one Journey, CallCoach 1–3 tasks/day, Focusmate one task/session. Nobody sequences goals adaptively.

## Landing page patterns that work

1. Outcome-verb headline + mechanism subhead. HabitKit "Habits you can actually see / One tap logs the day." Sunsama "Start Calm. Stay Focused. End Confident."
2. Proof stack under the fold: rating + count, user count, press, institutional credibility (Duke).
3. Daily loop as 3-step strip, not feature list.
4. Name the enemy. Maxi: "ChatGPT gives advice but no follow-through."
5. Transparent pricing + lifetime/founding anchor. FAQ answering "what if I miss a day" and cancellation.
